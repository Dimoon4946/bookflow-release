# Руководство пользователя

## Назначение системы

BookFlow предназначена для автоматизации работы библиотеки.

## Роли пользователей

### Администратор

Администратор может:

* просматривать пользователей;
* добавлять книги;
* удалять книги;
* просматривать заказы;
* оформлять выдачи книг;
* формировать отчёты;
* экспортировать отчёты в DOCX и XLSX.

### Пользователь

Пользователь может:

* входить в систему;
* просматривать каталог книг;
* оформлять заказ книги.

## Вход в систему

Для входа необходимо открыть страницу авторизации и ввести логин и пароль.

## Заказ книги

1. Выполнить вход.
2. Перейти в раздел «Книги».
3. Нажать кнопку «Заказать».
4. Заказ будет сохранён в системе.

## Отчёты

В разделе «Отчёты» доступны отчёты по книгам, пользователям, заказам и выдачам.

Каждый отчёт можно экспортировать в форматы DOCX и XLSX.

## Часто задаваемые вопросы

### Не удаётся войти

Проверьте правильность логина и пароля.

### Не отображаются книги

Убедитесь, что книги добавлены администратором.
