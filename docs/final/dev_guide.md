# Руководство разработчика

## Архитектура проекта

Проект построен по шаблону MVC.

### Models

Модели отвечают за работу с базой данных.

### Views

Представления отвечают за отображение интерфейса.

### Controllers

Контроллеры обрабатывают запросы пользователей и связывают модели с представлениями.

## Структура проекта

```text
public/
src/
  controllers/
  models/
  views/
docs/
init/
```

## Используемые технологии

* PHP 8
* MySQL 8
* HTML
* CSS
* Docker
* Docker Compose
* PHPWord
* PhpSpreadsheet

## Безопасность

Пароли пользователей хранятся в хэшированном виде.

Для ограничения доступа используются роли:

* admin
* user

## Docker

Для контейнеризации используется Docker Compose.

Сервисы:

* web
* db
* phpmyadmin

## Возможные проблемы

### Нет соединения с БД

Проверить параметры подключения.

### Не запускаются контейнеры

Проверить Docker Desktop и Docker Compose.
