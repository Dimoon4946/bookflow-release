# BookFlow

## Описание проекта

BookFlow — веб-приложение для автоматизации работы библиотеки.

Система позволяет управлять книгами, пользователями, заказами и выдачами книг, а также формировать отчёты с возможностью выгрузки в форматы DOCX и XLSX.

---

## Функциональность

### Администратор

- авторизация в системе;
- просмотр пользователей;
- добавление и удаление книг;
- просмотр заказов;
- оформление выдач;
- просмотр отчётов;
- экспорт отчётов в DOCX;
- экспорт отчётов в XLSX.

### Пользователь

- авторизация в системе;
- просмотр каталога книг;
- оформление заказа книги.
